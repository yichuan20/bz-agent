AI Panel Exception
The AI panel intentionally uses hardcoded hex values (#111111, #262626, etc.) instead of CSS variables. This ensures it stays dark regardless of the active theme mode. Use the --ba-ai-* tokens only for reference — never connect them to CSS variables in the AI panel code.
